# Contributing to the Project

## OpenNTF Contributors

This project is maintained by OpenNTF contributors. If you are interested in contributing, 
please review the [OpenNTF Project Contributor](https://openntf.org/main.nsf/page.xsp?name=Get_Involved) page.

## Contribution Guidelines

- Please fork the repository and create a new branch for your changes. Then submit a pull request for review.
- Keep the code style consistent with the existing codebase.
- Document your code and provide clear commit messages.
- Try to maintain 100% test coverage for any new features or changes.
- In case of any questions or issues, please reach out to the maintainers for guidance.
- Don't be afraid to submit a pull request for even small changes or improvements. Every contribution is valuable.
- Ask for help if you need it. The maintainers are happy to assist and provide guidance.

## AI-Assisted Development

Contributors are invited and expected to follow [AI Use Policy](AI_Use_Policy.md) when contributing to the project.

Use of AI is not prohibited, and contributors are not required to disclose ordinary assistance 
such as autocomplete, documentation proofreading, architectural discussion, or code review 
unless otherwise relevant to the contribution. Where AI materially generates implementation code,
contributors should disclose that use as described in the policy.

By submitting a contribution, contributors remain responsible for ensuring that their contribution is appropriate for inclusion in the project and complies with the project's licensing, quality, and review requirements.

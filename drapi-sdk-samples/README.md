# Drapi SDK Samples

This directory contains sample code demonstrating how to use the Drapi SDK to interact with the HCL Domino REST API. The samples cover common use cases and provide practical examples for developers to get started quickly.

## List of Sample Applications

- **[Sample 1](drapi-sdk-samples-standalone/README.md): Basic Authentication Example as a standalone Java application**
  - Demonstrates how to authenticate with the HCL Domino REST API using basic authentication.
  - Shows how to make a simple GET request to retrieve data from the server.
  - Include some examples to access field values through the `Document` interface.
